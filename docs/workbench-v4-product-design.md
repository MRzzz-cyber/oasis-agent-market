# Oasis 工作台 v4：从行情研究到确认交易

## 目标与本轮范围

让首次进入的用户知道可以问什么，并在同一工作区完成“选资产 → 研究 → 形成计划 → 检查测试资金 → 确认交易 → 查看回执”。保留已经成交验证过的 Hyperliquid 测试网签名与下单链路。

本轮已实现：行情侧栏、引导式提问、对话内资金卡片、测试网钱包抽屉、余额查询与成交后刷新、移动端收起行情栏、深色工作台。自动创建账号钱包属于下一阶段，当前没有接入钱包服务凭据，产品明确显示未启用，不产生虚构钱包地址。

## 参考布局的取舍

参考界面最有价值的设计是持续可见的市场上下文和宽敞的对话空间。Oasis 采用：

- 56–64 px 工具栏：工作台、图表、钱包、策略记录。
- 240–310 px 行情侧栏：搜索、加密/美股永续/宏观分类、价格、24 小时变化、更新状态。
- 中央区域：选择资产、四种引导问题、自由输入、模型选择、对话与交易卡片。
- 右侧钱包抽屉：现有钱包、测试 USDC、UETH、地址、官方测试币入口与执行入口。
- 小屏将行情栏收起为可展开面板，资金面板使用屏幕宽度。

以深灰绿为底、薄荷绿为主色，红绿只表示实际行情变化。不给市场列表填充不存在的市值、收益、成交或账户数据。

## 用户路径

1. 选择 ETH 或其他市场。选币只改变研究上下文，不创建订单。
2. 选择“分析当前行情”“制定买入计划”“检查交易风险”“了解交易基础”，也可自由输入。
3. 界面附加注明来源、市场类型、读取时间的行情上下文。读取失败或过期时只讨论方法，不编造价格。
4. 用户提出买入或资金需求后，出现“先检查交易资金”卡片。余额未知与余额为零严格区分。
5. 打开钱包抽屉，连接现有 EVM 钱包，读取 Hyperliquid 测试网 Spot 的 USDC/UETH。
6. 用户自行在官方测试网准备测试资产，再在 Oasis 预览 ETH 订单。目前只有 ETH 测试网现货可执行；其他标的用于研究。
7. 核对金额、网络、数量和限价；签署测试网助手授权，再单独确认订单。
8. 展示真实交易所回执。成交后重新读取余额；结果未知时锁定原订单，先查询，不自动重试。

## 行情与 AI 的边界

侧栏来源为 Hyperliquid 主网永续市场。股票类别是股票相关永续，不是证券账户里的股票现货；价格为市场中间价/参考价，不承诺其他交易所可成交价格。

REST 上下文提供前一日价格与成交额，WebSocket allMids 更新价格；断开时重连，失败时显示旧快照状态。提示词保留每个资产的更新时间，超过 90 秒不作为实时数据发送。

AI 的任务是解释证据、提出观察与暂停条件、补全意图。AI 不能决定签名身份、收款地址、充值目标或扩大金额。页面与确定性规则生成订单参数，用户确认才可提交。AI 在没有账户工具数据时不能说“你的余额为零”或“充值已经完成”。

## 钱包产品方案

### 当前交付

沿用 Rabby/MetaMask 等现有钱包。仅内存持有 provider；不读取、生成或保存用户私钥。钱包抽屉显示“账号钱包尚未启用”。只链接官方测试网领取与账户页面，不开放主网充值或主网下单。

### 注册自动创建钱包：推荐嵌入式用户钱包

建议采用 Privy 用户钱包，通过现有 Google 身份映射用户所有权。不要把随机私钥写入 Cloudflare 数据库或浏览器本地存储作为正式账户钱包，也不要将交易授权助手误称为用户资产钱包。

启用前的外部依赖：

- 建立 Privy 应用、配置允许的域名及 Google/自定义身份验证。
- 确认用户所有权、登录恢复、导出与撤销方式。
- 配置相应公开应用标识、服务器认证凭据与身份验证密钥；私密凭据只进入服务端 Secret。
- 完成新的用户授权、凭据校验与恢复演练后，才启用自动创建。

建议账户钱包状态：未启用 → 待创建 → 创建中 → 可用 / 可重试失败。Google sub 与提供商用户/钱包 ID 在服务端一对一保存。幂等创建；重复登录返回相同钱包；错误不会回滚已经成功的 Google 登录。余额必须来自查询，不能由“钱包创建成功”推断有钱。

用户钱包与 Agent 会话钱包是两个不同对象：前者持有资产，后者仅在用户明确授权的任务与预算内执行。当前助手授权在协议层可能比应用的本次金额限制更宽，界面继续明确说明并保留官方撤销入口。

## 验收与指标

- 行情失败仍可讨论；不填充假价格，不将失败显示成零余额。
- 侧栏切换资产不跳出工作区；WebSocket 更新不重建输入控件或抢走焦点。
- 选择提示词后保留自由编辑能力；当前 MVP 真实模型调用仍使用已有登录/激活机制。
- 钱包连接、读取余额、授权与提交保持独立；取消签名可以恢复。
- 成交回执保留真实订单号、数量、均价；成交后余额读取失败有独立提示。
- 账号钱包未启用时不展示可充值的新地址。
- 跟踪引导问题点击→首次有效回答、计划→预览、预览→确认、交易所接单/成交、余额刷新成功率；现阶段不伪造这些指标。
