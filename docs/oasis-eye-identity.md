# Oasis：B 方向的小眼睛

采用横向椭圆 O 与一枚瞳孔，保留 B 的简洁轮廓。默认瞳孔位于右上方；鼠标移动时，仅在外圈内部轻微跟随。网页导航、工具栏、欢迎标识与 AI 助手头像共用相同几何。

- 主色：浅绿 `#B6EE86`；单色稿：近黑 `#101312`。
- 主标 SVG：`apps/frontend/brand/oasis-eye.svg`，透明背景，`viewBox="0 0 80 56"`。
- favicon：`apps/frontend/brand/favicon.svg`，深底浅绿标记。
- 瞳孔跟随由本地指针事件计算，不请求接口，不保存鼠标轨迹。
- 停止移动后动画自动结束，不维持空转帧循环。
- 触屏保持静态；启用“减少动态效果”时保持静态，并对偏好变更即时响应。
- 新生成的助手消息会自动挂载标识；离开窗口后恢复默认视线。
