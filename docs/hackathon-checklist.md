# ETHOnline submission checklist

## Hedera AI & Agentic Payments

- [ ] Live x402-gated service on Hedera testnet or mainnet.
- [ ] Settlement through Blocky402 facilitator.
- [ ] Agent completes at least one real paid request end-to-end.
- [ ] Public README documents setup, architecture, and payment flow.
- [ ] Demo video under five minutes shows the paid request executing.

## ETHOnline project submission

- [ ] Preserve continuous Git history for hackathon work.
- [ ] Clearly distinguish pre-existing work from new hackathon work.
- [ ] Include repository link and project description.
- [ ] Upload a two-to-four-minute demo video at 720p or higher.
- [ ] Select Hedera as a partner prize; select The Graph only if live Graph data is load-bearing to a decision.
- [ ] Disclose AI-assisted development, prompts/specs if applicable, and human review.

## Demo script

- [ ] User sets ETH strategy, risk controls, and 0.20 HBAR research budget.
- [ ] Agent discovers two services and pays for them via x402.
- [ ] Market and risk evidence return.
- [ ] Agent rejects an unsafe trade and explains why.
- [ ] Show payment transactions and audit record.
