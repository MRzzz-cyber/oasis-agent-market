完成账号钱包配置

为现有 Google 登录建立 Privy 身份验证。此页面只在本机生成密钥，不会将私钥上传、写入浏览器存储或发送到聊天。

正在检查线上公钥…

01 · 本机生成

生成一次身份签名密钥

这是 Oasis 身份服务的签名密钥，不是用户钱包私钥。生成后保持本页打开，刷新会丢失尚未保存的密钥。

02 · Cloudflare

添加两个运行时变量

打开 Cloudflare → oasis-agent-market → Settings → Runtime variables and secrets → Production。分别新增并保存以下两项。

OASIS_AUTH_PRIVATE_KEYSecret · 加密

值为完整 PEM 私钥。只粘贴到 Cloudflare 的 Secret 输入框，不要提交 Git 或发送给任何人。

OASIS_AUTH_PUBLIC_JWKText · 明文

值为完整的公钥 JSON。公钥用于让 Privy 验证 Oasis 身份。

App ID、Client ID、issuer 和 key ID 已在项目部署配置中，无需重复填写。

03 · Privy

检查公钥，再保存 JWT 配置

确认公钥发布成功后，回到 Privy 的 JWT integration 页面，点击 Save changes。若本页生成了密钥，会核对线上公钥与本页密钥是否一致。

https://oasis-agent-market.zqsanjingshou.workers.dev/.well-known/jwks.json
04 · 启用

最后开启账号钱包

在 Privy 保存验证成功后，回 Cloudflare 新增 Text 变量 PRIVY_ENABLED，值为 true，保存并部署。重新登录 Oasis，测试创建或恢复账号钱包。

本次仍只测试 Hyperliquid Testnet。新钱包的余额独立于旧钱包，不会自动转入旧钱包的测试资金。

这是部署配置工具，不会修改服务器设置、创建交易或自动授权钱包。
